# Platform Version 2

The hands-on guide for building plugins on Graph **Platform Version 2**, plus the library reference for each 2.x release.

## Plugin Development Guide

* **[Creating Plugins](creating-plugins/index.md)** — set up a plugin project and build your first plugin from scratch.
* **[Developing Datatypes](developing-datatypes/index.md)** — define the data shapes that flow through your graph.
* **[Developing Widgets](developing-widgets/index.md)** — build Lit web components that view and edit datatype values.
* **[Developing Nodes](developing-nodes/index.md)** — build computational nodes with typed input and output ports.
* **[Developing Utilities](developing-utilities/index.md)** — build utility plugins that share reusable code across plugins.

## Platform Library Reference

Every Graph 2.x release ships a fixed set of libraries your plugins can import directly at runtime — Lit, Spectrum Web Components, the `@graph/*` platform packages, and more. Pick a plugin's platform version by setting `platformVersion` in its manifest (see [Platform Versioning](../platform-versioning/index.md)), then open the matching release below to see what you can import.
